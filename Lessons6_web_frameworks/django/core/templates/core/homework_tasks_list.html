    {% for task in tasks %}
  • {{ task.title }} (id: {{ task.id }}, slug: {{ task.slug }}) — відкрити за id — відкрити за назвою (slug)

Приклад прямого посилання за id → /app/homework/3/id/2/

Приклад за slug → /app/homework/3/name/docs/
